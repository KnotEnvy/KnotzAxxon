# Production asset retention devlog

Prepared 2026-11-14 on SuperBeast as a pre-release cleanup index. These frozen initial submissions were user-approved for release on2026-11-14. Formal Opus reviews and review-driven fix passes remain at zero; user release approval does not imply that formal review is complete.

The 21 initial trees went from 1,497 files / 373.28 MiB to 844 retained original files / 146.78 MiB, plus 42 per-initial retention records. The archived pre-existing integration snapshot went from 55 files to 38. Its Classic and Modern captures remain in 17 asset folders. The new cargo-kit and covered-fighter integration directories are left to the primary integration pass and are excluded from this snapshot.

For full initial render/contact-sheet evidence, extract that asset’s initial-tree archive listed in retention.json into a writable copy before running evidence scripts. Restore original integration captures from the separate integration-evidence archive. Core generator/build/verification/runtime files and packed blend/GLB bytes are unchanged.
