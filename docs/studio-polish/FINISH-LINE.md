## Completion boundaries

The goal is a finished, validated facelift of the existing eight-sector game, not an expanding feature wishlist. Existing procedural bolts, halos, paint and shader sky need no Blender conversion merely for completeness. The previous formal Opus art-review/fix rounds remain explicitly deferred after user approval of the shipped models; the new nonspatial Opus crew does not count as that art review. Hardware FPS, physical latency and human audio judgements are not established by software rendering or CPU cadence tests.

The user explicitly authorizes pushing, merging and cleaning up when ready. No additional routine permission is needed; validation still precedes publication. Current live release remains unchanged until that work is complete. No deadline-based waiver of failed checks or false whole-game completion claim is permitted.
